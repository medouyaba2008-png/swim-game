# 🏊 السبّاح الماهر | Swimmer Game

لعبة سباحة بالعربية: اضغط مطوّلًا للصعود، وأفلت للنزول، واقفز من الماء لتجمع الحلقات 🪙، وتجنّب 🪼 و🦈 و🐙.

An Arabic arcade swimming game (HTML5 canvas) wrapped as a Windows desktop app with PyQt6 WebEngine.

## اللعب في المتصفح
افتح `swim-game.html` مباشرة.

## تطبيق ويندوز
**الطريقة 1 – تنزيل جاهز:** من تبويب **Actions** افتح آخر تشغيل ناجح ونزّل `SwimGame-windows`.

**الطريقة 2 – البناء محليًا:** شغّل `build.bat` (يتطلب Python 3.10+). الناتج في `dist\SwimGame\SwimGame.exe`.

## التحكم
- ضغط مطوّل / مسافة: صعود  •  F11: ملء الشاشة
